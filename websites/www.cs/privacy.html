What this site counts

So I can see which games people play and where they get stuck, this site counts visits to its pages and games. It does this itself: no cookies, no advertising, and nothing is sent to anyone else.

What is counted

  • Which page or game was opened, when, and for how long it was on screen.
  • Whether you came from Facebook, Discord, a search engine, another page here, or nowhere in particular. Only that kind is kept, never the address you came from.
  • Whether the device is a phone, a tablet or a computer.
  • A few things done in the games, such as starting a level, winning it, asking for a hint, hosting a room or saving a high score.

How visits are told apart

Your browser keeps a random number for this site in its own storage, so a second visit can be told from a first. It is not linked to your name, your account or anything else about you, and clearing this site's data removes it. For one day at a time the server also uses a scrambled code made from your network address and browser; the address itself is never stored, and the key that scrambles it is thrown away at the end of each day.

How long it is kept

These records are kept indefinitely: each visit as described above, daily totals such as how many people played each game that day, and, to tell a new visitor from a returning one, the random number from your browser with the first and last day it was seen.

Crete's shared Endless levels

When The Island of Crete makes an Endless level, it sends the maze to this site's server so other players can play it. While the game is open and idle, it also uses a little of your device's spare time to check mazes other players made; the game's menu has a Help Check Endless Levels switch that turns this off. Only mazes and the numbers that made them are kept. Your browser keeps a random number for the game, so the server can tell that two checks came from two different devices; while a maze waits for its checks (three days at most) the server keeps a scrambled code made from that number, and one made from your network address whose key it deletes within six days. To stop too many requests from one place, it also keeps that network code for an hour. Neither is linked to your name or anything else about you. Do Not Track or Global Privacy Control stops the game sending mazes and checks; it still plays the mazes others shared.

Turning it off

Turn on Do Not Track or Global Privacy Control in your browser, and this site sends nothing at all. Blocking this site's storage also works: visits are then still counted, but each day looks like a first visit.

Only the site's owner can see the numbers. Nothing here shows them to visitors.
